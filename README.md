###	1.Propósito y contenido del Repositorio: mundial
El propósito de este repositorio es alojar, organizar y mantener todo el desarrollo del sitio web informativo e interactivo sobre el Mundial de Fútbol, tal como lo he diseñado y estructurado. Aquí se encuentra todo el código fuente, archivos y recursos que conforman el proyecto, gestionado completamente mediante Git y GitHub para tener un control seguro y ordenado de mi trabajo.

###	2.Estructura y archivos del proyecto
Dentro de este repositorio se encuentran todos los archivos que construyen el sitio, los cuales son:

index.html: Página principal y entrada al sitio.
calendario.html: Sección con el calendario y programación de los partidos.
impacto.html: Página informativa sobre la relevancia e impacto del torneo.
sedes.html: Información sobre las ciudades y estadios donde se juegan los partidos.
estilos.css: Hoja de estilos que define el diseño, colores, fuentes y apariencia visual, utilizando también el framework Bootstrap para que se adapte a cualquier dispositivo.
scrypt.js: Archivo con la lógica, funciones y toda la interactividad del sitio, programado con JavaScript y jQuery.
Imágenes (01.jfif, 02.jfif, 03.jfif, 04.jfif): Todos los recursos gráficos e ilustraciones que dan vida al contenido.
README.md: Documento descriptivo con la información general del proyecto.
